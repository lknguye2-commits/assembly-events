Process

How a project gets assembled

Four stages, the same order every time — so nothing gets built before the foundation is set.

01

Brief

A working session to pin down objective, audience, budget, and date — the fixed points everything else is built around.

02

Blueprint

A full event plan: venue, vendors, timeline, and budget laid out for sign-off before anything is booked.

03

Build

Contracts, bookings, and coordination across every vendor — run by us, visible to you.

04

Execute

On-site management from load-in to load-out, with a single point of contact handling every issue that comes up.
